A SELF-DIRECTED CURRICULUM

From the ground up

A roadmap for building real understanding of how computers and software actually work — not just how to make a webpage do things, but why the things underneath it behave the way they do.

PHASE 0

Logic foundations

WEEKS 1–2

Make loops, conditionals, and functions second nature before syntax gets in the way. PYTHON

  • Variables, data types, operators
  • if / else, switch-style branching
  • for / while loops — and when to choose which
  • Functions: parameters, return values, scope
  • Arrays and lists, basic manipulation
  • 20–30 small logic drills, building past FizzBuzz-level
Python here, on purpose — even though it's "for projects" later. The goal is separating learning to think in logic from learning C++'s strict syntax, so you don't get stuck on semicolons instead of ideas.
PHASE 1

C++ & how computers work

WEEKS 3–8

The part web development usually hides from you — what's actually happening underneath. C++

  • Syntax and the compilation process — what a compiler does
  • Memory: stack vs. heap, pointers, references
  • Data structures built from scratch: arrays, linked lists, stacks, queues, hash maps, trees
  • Core algorithms: searching, sorting, recursion
  • Big-O notation — felt, not just memorized
Checkpoint: you should be able to explain why inserting at the front of an array is O(n) but a linked list insert is O(1) — and actually feel the difference, not just recite it.
PHASE 2

Software design & architecture

WEEKS 9–12

Now that you understand what's happening underneath, learn to organize code well on top of it.

  • OOP done properly: encapsulation, inheritance, polymorphism, composition over inheritance
  • SOLID principles
  • Design patterns you'll actually use: Factory, Singleton, Observer, Strategy
  • Basic system design: client/server, database, API, caching — how the pieces fit
This is where your existing web skills reconnect to the theory — you'll recognize pieces of systems you've already touched.
PHASE 3

Build real projects

WEEKS 13–16+

Apply everything, increasing in scope. PYTHON

  • CLI tool (e.g. a task manager) — clean structure, no framework crutches
  • Small API backend with a database — real architecture decisions
  • A larger project combining backend + web skills + good design — your proof point for "robust small system"
This phase doesn't have a hard end date — treat weeks 13–16 as the start of an ongoing practice, not a finish line.
NOTE — This is a living plan. Adjust pace against the 5–10 hrs/week budget as life allows; the order of phases matters more than the exact week count.
