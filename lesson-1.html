LESSON 1 — YOUR FIRST INSTRUCTION

Setting up C++ & Hello, World

A working setup and one real program you wrote yourself. Nothing fancy — just proof the machine is listening.

BEFORE YOU START

What you're actually installing

C++ code doesn't run on its own — it has to be compiled first, meaning translated into instructions your machine's processor can actually execute. So you need two things: a place to write code (VS Code), and a compiler to translate it. These steps are for Windows.

STEP 1

Install VS Code

→

Go to code.visualstudio.com and download the installer for your system. Run it, accept the defaults — nothing unusual here.

STEP 2

Install a compiler

a

Install MSYS2 from msys2.org — it's the easiest way to get a real GCC compiler on Windows. Run the installer with defaults.

b

Open "MSYS2 UCRT64" from your Start menu (not a regular terminal) and run:

pacman -S mingw-w64-ucrt-x86_64-gcc
c

Add the compiler to your system PATH so VS Code can find it. The folder to add is usually:

C:\msys64\ucrt64\bin

Search "Edit the system environment variables" in the Start menu → Environment Variables → find Path under your user variables → Edit → New → paste the folder above.

FUN FACT

The C++ compiler doesn't just translate your code once — it goes through several stages (preprocessing, compiling, assembling, linking) before producing a runnable file. Every time you hit "run," all of that happens again in a fraction of a second.

STEP 3

Add the C++ extension in VS Code

a

Open VS Code. Click the Extensions icon in the left sidebar (looks like four squares), search for "C/C++" (published by Microsoft), and click Install.

STEP 4

Verify the compiler is actually found

a

Open a terminal inside VS Code: Terminal → New Terminal from the top menu. Run:

g++ --version

You should see a version number printed back. If you see "command not found" instead, the compiler isn't on your PATH yet — see the troubleshooting box below.

IF SOMETHING'S NOT WORKING
"g++ is not recognized"
The PATH wasn't updated correctly, or VS Code was open before you changed it. Close VS Code completely and reopen it — PATH changes only apply to new terminal windows.
"pacman: command not found" inside MSYS2
You opened the wrong terminal. Make sure you launched "MSYS2 UCRT64" specifically from the Start menu, not "MSYS2 MSYS" or a regular Command Prompt.
Nothing happens when you click "Run"
Make sure your file is saved with a .cpp extension first — VS Code needs that to know what it's running.
STEP 5

Write your first program

a

Create a new folder anywhere you'll remember (e.g. cpp-lessons), open it in VS Code via File → Open Folder, then create a new file named exactly:

hello.cpp
b

Type this in — typing it yourself (not pasting) is worth it the first time:

hello.cpp
// hello.cpp — my first C++ program
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
c

Save the file, then in the VS Code terminal, run:

g++ hello.cpp -o hello.exe
.\hello.exe

You should see Hello, World! printed in the terminal.

WHAT YOU JUST WROTE

Breaking it down, line by line

You don't need to memorize any of this yet — just get a feel for what each piece is doing.

// comment
A note to humans. The compiler ignores anything after // — it's purely for people reading the code later, including future you.
#include <iostream>
Pulls in a chunk of pre-written code that lets you print things to the screen. You're borrowing tools someone else already built, rather than reinventing them.
int main() { }
Every C++ program needs exactly one main — it's the entry point. When you run the program, this is where execution starts.
std::cout <<
"Send this to the screen." The << arrows point the text toward the output.
return 0;
Tells the operating system the program finished without errors. 0 means "all good" — it's a convention you'll see everywhere.
FUN FACT

"Hello, World" as a first program dates back to a 1972 internal memo at Bell Labs, and was popularized by Brian Kernighan's 1978 book on the C language. It's been the traditional first program in nearly every language since — including this one.

YOUR ASSIGNMENT

Make it say something else

Confirm your setup actually works end to end — then push past copy-paste.

  • Verify: run g++ --version and confirm a version number prints — don't skip this.
  • Get hello.cpp running exactly as shown, and actually see "Hello, World!" in your terminal.
  • Change the message to print your own name instead — e.g. "Hello, Naa!" — and re-run it. Re-run means: save the file, then repeat both terminal commands. The compiler has no idea you changed anything until you compile again.
  • Add a second line that prints something else entirely — a fact about yourself, today's date typed manually, anything. Hint: you'll need a second std::cout << ... << std::endl; line, right below the first, inside the same main().
EXPECTED SHAPE (fill in your own text)
#include <iostream>

int main() {
    std::cout << "..." << std::endl;
    std::cout << "..." << std::endl;
    return 0;
}
